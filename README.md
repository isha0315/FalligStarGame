# ⭐ Catch The Stars Game

An interactive arcade-style browser game built using HTML, CSS, JavaScript, and AWS Cloud Services.

Players must catch falling stars using a basket before time runs out. The game includes level-based missions, online score tracking, particle effects, and a real-time leaderboard powered by AWS.

---

# 🎮 Features

- Responsive arcade-style UI
- Falling star animation
- Basket movement controls
- Multiple game levels
- Timer-based missions
- Dynamic difficulty system
- Particle effects
- Online score saving
- Global leaderboard
- AWS cloud integration
- Mobile & desktop support

---
